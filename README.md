# عاداتي · Habit Tracker

تطبيق ويب لتتبّع العادات اليومية. عادات بأيام محددة، سلاسل التزام (حالية وأفضل)، خريطة حرارية لآخر ١٦ أسبوع، ونسب الإنجاز لآخر ٧ و٣٠ يوم.

- بدون مكتبات وبدون build: HTML + CSS + JavaScript.
- البيانات في `localStorage` على الجهاز فقط (مفتاح `habit-tracker-v1`)، مع تصدير واستيراد JSON.
- منطق الحساب في `logic.js` وعليه اختبارات: `node --test`.

## قواعد الحساب
- السلسلة بتعدّ الأيام المطلوبة بس. اليوم اللي مش من أيام العادة بيتخطّى ومبيكسرش السلسلة.
- اليوم الحالي لو لسه متعلّمش مبيكسرش السلسلة (لسه معاه وقت).
- ممنوع تعليم يوم في المستقبل أو قبل تاريخ إنشاء العادة.
- الأسبوع في الخريطة بيبدأ يوم السبت.

## حدود معروفة
- مفيش مزامنة بين الأجهزة (النسخة الاحتياطية يدوية).
- التاريخ حسب ساعة الجهاز والمنطقة الزمنية بتاعته.

Built with AI assistance.
